# Slot Aset Gambar SMAK

Semua file JPG di folder ini adalah slot tetap untuk dashboard admin. File placeholder
merupakan gambar valid, bukan file 0-byte, agar Flutter tidak mengalami error decode.
Dashboard admin dapat mengganti isi file tanpa mengubah path pada kode.

## Folder utama

- `banners/`: banner setiap halaman.
- `landing/`: konten gambar halaman beranda.
- `profil/`: foto halaman profil sekolah.
- `akademik/`: foto halaman akademik.
- `kesiswaan/`: foto umum halaman kesiswaan.
- `osis/`: pengurus, program, dokumentasi, dan testimoni OSIS.
- `ekstrakurikuler/`: foto setiap kegiatan ekstrakurikuler.
- `prestasi_siswa/`: foto prestasi dan dokumentasi siswa.
- `ppdb/`: foto lingkungan, fasilitas, dan testimoni PPDB.
- `sarana_prasarana/`: foto fasilitas sekolah.
- `staff/`: foto kepala sekolah, guru, dan karyawan.

## Ketentuan upload

- Banner disarankan minimal `1600 x 600` piksel.
- Foto landscape disarankan minimal `1200 x 800` piksel.
- Foto profil disarankan minimal `600 x 800` piksel.
- Gunakan JPG untuk foto dan PNG untuk logo.
- Pertahankan nama file agar halaman tidak perlu diubah kembali.
- Jangan menimpa `logo_sekolah.png` kecuali memang memperbarui logo resmi.
